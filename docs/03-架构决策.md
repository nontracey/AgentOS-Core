## ADR-0011

**首版集成顺序**

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-09-27 |
| 状态 | 范围已被后续决策更新；安全先行原则保留 |
| 决策 | 先形成持久状态、权限和成果基础，再集成任务闭环。具体版本范围由开发计划裁定。 |
| 理由与影响 | 分域接入可降低集成风险；历史业务模板不作为当前产品目标。 |
| 复审条件 | 范围变化时更新任务与验收，不重复维护阶段计划。 |

## ADR-0022

**集成底座与成熟运行时优先**

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-10-01 |
| 状态 | 已采纳；补充 ADR-0019/0020，更新 ADR-0021 的本次范围 |
| 决策 | 公司优先既有框架/身份/业务系统，开源项目优先成熟组件。Codex 承载实际推理/工具循环/压缩，Temporal 持久编排，React Flow 可视编辑，Authlib/PyJWT 接 OIDC/ID4/JWT，官方 MCP 双向互通，WeKnora 以 Knowledge Port 接入。模型优先复用已有端点，设备无关；网关按实际兼容结果选择，云端显式按出域策略接入。 |
| 保留自研与原因 | 资源授权、审批绑定、效果幂等/对账、成果检查与必要适配器是本项目差异。固定报告/协作作为 Temporal 业务节点，保留检查/返修语义。旧 TaskPlan 是兼容契约，不能冒充新引擎；scripted 仅用于确定性测试。本地个人登录、SQLite/文件成果和内置轻量检索为受限兼容选择，逐项比较、成本和退出路径见 [方案 §10](08-集成底座改造方案.md#10-开源优先复核与保留例外)。 |
| 维护与许可 | 锁定 Codex 实验动态工具版本，持续做协议契约测试，不 fork 引擎；承担当期 Temporal/WeKnora 运维成本。核心许可清单见 contracts/oss-licenses.json，不将商业目录或容器全部依赖视为已审完。 |
| 退出与复审 | Runtime/Workflow/Identity/Knowledge Port 隔离实现；历史成果/账本保留，未完旧引擎 run 暂停迁移。企业已有组件通过适配替换默认件。供应商或上游版本变化重新验工具、压缩、权限、恢复。 |

## 3. 资料使用

原始资料的核对日期和引用保留于历史决策资料。上游协议、SDK、许可和能力有变化时，按实际锁定版本复核；历史调研不能直接作为当前运行保证。

当前实现参考 [总体架构](01-总体架构.md) 和 [工程设计](02-工程设计.md)，当前范围与剩余事项见 [开发计划](04-开发计划.md)。

## ADR-0024 私有草稿与受控能力装配

<a id="adr-0024"></a>

| 项目 | 内容 |
| --- | --- |
| 状态 | 已采纳；CAP-02 负责实现与验证 |
| 决策 | 编辑草稿按主体持久化并使用 revision 条件写；发布仍不可变。固定版本工作流经薄 ToolPort Adapter 启动，MCP 外部 Agent 使用官方 SDK。助手只能生成连接草稿，管理员核对具体配置/hash 后登记为停用连接，再显式探针/启用 |
| 复用与自研原因 | React Flow 负责画布，RJSF/AJV 负责 schema 表单，Temporal 负责执行，官方 MCP SDK 负责协议。它们不替平台决定资源归属、审批、预算与配置变更，因此只补这些治理规则和必要适配器，不 fork 执行/表单/协议引擎 |
| 成本与兼容 | 无新增软件依赖。增加一张私有草稿表、委派预算关联表及兼容列迁移；草稿独立于 FlowGraph，旧发布定义/工具摘要不因增加草稿字段改变。委派受理与父预算预留同事务；子任务终态结算，未决用量保守计入 |
| 边界 | 工作流启动回执仅表示受理，不表示成果完成。自主委派最多一层，分配不超过父任务剩余预算一半，保留父任务继续报告的额度；任务状态查询仍核权。外部 Agent 先支持 MCP，不宣称 A2A/跨协议通用委派；本机命令不会在草稿生成或登记时执行 |
| 许可与退出 | 继续遵守现有 OSS 清单；配置与输入保留标准 JSON Schema/MCP，运行契约保留 FlowGraph。更换编辑器或新增公司协议只替适配层，不迁移治理历史；企业已有配置中心可经 Adapter 替换默认草稿存储与审阅入口 |


## ADR-0025 有界数据工具与统一成果交付

<a id="adr-0025"></a>

| 项目 | 内容 |
| --- | --- |
| 日期与状态 | 2026-10-03，已采纳，POLISH-01 |
| 决策 | 默认能力服务真实材料到成果闭环，演示工具退出真实模型目录；普通写文件接入现有 Asset，而非另建文件交付体系 |
| 复用与范围 | CSV/JSON/十进制数使用 Python 标准库；仅增加材料授权、任务绑定、坏行诊断、结果限额、审批和不可变版本薄适配。继续由 Codex 推理、已有 executor 治理，React Flow/RJSF 配置 |
| 成本与兼容 | 无新依赖/许可变化；小文本分析无需 pandas/数据库/沙箱解释器的安装及维护成本，不支持 Excel、大表、任意表达式或自动联网。旧显式示例引用保持可解析，新目录隐藏；不回填旧历史成果 |
| 退出路径 | 企业已有数据平台或成熟大型分析服务经 ToolPort/MCP 接入，替换有界分析 Adapter；保留通用材料 ID、审批、成果/版本与幂等账本，无需迁移执行引擎 |
