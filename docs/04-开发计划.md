## 1. 产品目标与当前范围

AgentOS 是可自托管的 AI 集成与治理底座：连接散落的模型、Agent、知识、工具、技能、身份和业务系统，提供统一任务、权限、审批、成果与成本。默认提供 Web UI，同时提供 HTTP 与 MCP，后续可连接 IM 等渠道。

产品按“一个核心，能力按需接入”设计，不把个人联验设备、模型别名或机器数量写成用户要求。核心可以连接同机、远程或云端已有服务；当前单核心可用，多副本核心/生产 HA 待验。个人任务工作台是首个入口，不限制产品只用于个人或特定设备组合。

当前为集成底座候选版。已确认的 REBASE-01 核心改造完成，工具目录、知识关闭与参数表单已实现，跨工作流/外部 Agent 装配仍需完善；不能将“外部组件已接通”当成完整的即接即用。源码核对与下一步设计见 [能力接入模块](modules/capabilities.md)。

本轮范围为已授权的 CAP-01 前三项：知识关闭、统一工具目录、工作流自动同步与成熟 schema 表单。产品修改只在独立核心，个人仓库仅更新维护文档及版本锁；适用检查和隐私复核通过，只本地提交，不推送。受控接入助手、工作流/外部 Agent 自主选择及 Docker 实际部署后置。

## 2. 当前实现

| 部分 | 代码当前支持 | 主要边界 |
| --- | --- | --- |
| 核心与 UI | 默认同源工作台、HTTP、入站 MCP、持久任务/成果与治理 | scripted 是验证默认；真实 AI 需要 Codex 和模型端点，编辑器需 build |
| 自主任务 | Codex 推理、工具选择、上下文压缩、暂停恢复 | 仅选择当前提供的工具；不能自动安装服务或任意委派外部 Agent |
| 工作流 | Temporal、React Flow、不可变版本、参数绑定、分支/等待/自定义 Adapter | Temporal 可不配置；持久图工作流需要接入；定时触发/独立 Webhook 未实现 |
| MCP / Skill / 节点 | 官方 SDK 注册发现工具、双向 MCP；Skill 固定版本；授权节点配对 | 统一工具目录与按 TTL 自动刷新；Skill 不天然是函数，配对不等于实时在线 |
| 知识 | 内置 SQLite 或 WeKnora；来源绑定、检索前过滤、回查、删除和对账 | 可明确 disabled，工具/MCP/UI 同步关闭；外部故障不静默回退 |
| 身份 | 本地身份、OIDC/ID4、受信 JWKS JWT、独立 HS256、稳定主体映射 | 真实企业 IdP 与长任务委托续期待实际接入；到期不自动扩大原授权 |
| 模型治理 | 可配置网关/模型名，调用及压缩前预算和出域裁定 | 换端点需验证协议兼容；结构化限流暂停，不静默换提供方 |
| 企业扩展 | 项目/企业额度/渠道 Port 与合成项目 Adapter | 真实旧系统、额度分配、IM 未上线 |

公开验证摘要与可复现命令见 [验证说明](validation.md)。原始现场记录与截图留在忽略的本地目录；不以历史测试结果证明当前 HEAD 全部通过。

本轮完成前两行覆盖的核心装配、目录与编辑体验，第三行保留后续，复用现有开源执行与协议：

| 工作块 | 改什么 | 验收例子 |
| --- | --- | --- |
| 核心与开关 | 已支持知识明确 disabled；工具/MCP/UI 同步；Temporal 启动失败隔离；不删除旧数据 | 无 WeKnora/Temporal、关闭知识，UI/HTTP/MCP 和普通 Codex 任务仍可用；不会公布关闭的工具 |

| 自主与接入助手 | 待实现：已发布工作流/外部 Agent 经受控 Adapter 暴露；入站 MCP 接入助手复用治理 | 用户只给目标可选已授权能力；其他 Agent 能辅助接入，但修改连接/权限需确认具体草稿 |

本轮验证：444 passed、6 skipped；Ruff、mypy、导入/契约/依赖门禁及编辑器 typecheck/build 通过；独立 wheel 安装通过。Tabbit 验证参数填写/发布、停用自动同步保留草稿、390px 窄屏、旧接口兼容和 SW 缓存升级。全部为合成服务/机制与浏览器验证，没有本轮真模型、物理手机或 Docker 验收。

具体契约和边界见 [能力接入模块](modules/capabilities.md#2-统一工具目录与治理)。不新写执行循环、通用调度引擎或任意代码插件平台；表单组件使用 RJSF 6.11.0/AJV8，兼容 React 19，许可 Apache-2.0；退出保留标准 schema。

## 5. 其他保留缺项

| 缺项 | 下一动作 |
| --- | --- |
| 工作流外部触发 | 实际需要时接 Temporal Schedule / 统一受理 Webhook，不另写定时引擎 |
| 真实企业集成 | 根据 IdP/旧项目/额度/IM 的实际协议配置 Adapter；合成样例不冒充上线 |
| 手机与 HTTPS | 真机可信入口验证上传、审批、预览/下载、断网恢复和撤权；模拟视口不代替 |
| 三次独立自用 | 使用者本人发起、检查、修改和下载并记录，AI 不代写验收 |
| 多副本与 HA | 有明确需求再验证共享状态、租约、迁移和恢复；外接多台服务不等于分布式核心 |

## 6. 维护与停止条件

先查 Git 状态，读取本文件和 [当前交接](dev-notes.md)，按需求 ID 定位代码。所有状态/待办统一修改本文；交接只保留当前任务、变更、验证、未完成与下一动作。

本轮前三项完成适用检查并本地提交后交付；后续产品功能按明确范围实施。API/授权/状态变更跑行为、安全和恢复检查，发布完整门禁见 [工程设计](02-工程设计.md#10-验证与交付)。公开仓库保留当前设计、必要 ADR、契约与验证摘要，本地历史和原始证据不参与公开文档检查，也不作为链接必需文件。
