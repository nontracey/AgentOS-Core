## 1. 产品目标与当前范围

AgentOS 是可自托管的 AI 集成与治理底座：连接散落的模型、Agent、知识、工具、技能、身份和业务系统，提供统一任务、权限、审批、成果与成本。默认提供 Web UI，同时提供 HTTP 与 MCP，后续可连接 IM 等渠道。

产品按“一个核心，能力按需接入”设计，不把个人联验设备、模型别名或机器数量写成用户要求。核心可以连接同机、远程或云端已有服务；当前单核心可用，多副本核心/生产 HA 待验。个人任务工作台是首个入口，不限制产品只用于个人或特定设备组合。

当前为集成底座候选版。已确认的 REBASE-01 核心改造完成，工具目录、知识关闭与参数表单已实现，固定工作流启动、MCP 外部 Agent 和接入草稿已补齐；不能将“外部组件已接通”当成完整的即接即用。源码核对与下一步设计见 [能力接入模块](modules/capabilities.md)。

CAP-01 前三项已完成：知识关闭、统一工具目录、工作流自动同步与成熟 schema 表单。VALIDATE-01 已完成必做验收：安全升级个人实例、已有真实模型闭环、真实图工作流、干净克隆安装、隔离容器启动/持久化和备份恢复。产品修改只在独立核心，个人配置和凭据仅在部署仓库的受保护位置；只本地提交，不推送。CAP-02 补齐受控接入草稿、固定工作流启动与 MCP 外部 Agent，其他协议仍通过后续适配器接入。

UI-01 按已确认方案升级首页、统一工具目录、工作流列表/编辑和企业角色呈现，复用现有 JS 模块、React Flow、RJSF/AJV 与同源 API；不迁移后端或引入第二套执行状态。

POLISH-01 完成任务交付与默认能力审查：首页、任务、成果库与能力中心统一视觉层次；普通写文件同步登记不可变成果，材料发现、CSV 检查与 JSON 字段查询进入同一工具目录。上传材料不再隐式改成报告模板，演示工具在真实运行环境默认隐藏；保留旧明确引用的工作流兼容。

UI-02 按用户“UI 仍像工程后台”的反馈重排阅读层次：首页突出目标输入，任务答复和成果优先，完成执行记录折叠，技术指标按需展开；暖白/石墨/苔绿主题统一导航与组件。复用现有 JS、Markdown 安全渲染和同源 API，不增加框架或改变服务端裁定。

## 2. 当前实现

| 部分 | 代码当前支持 | 主要边界 |
| --- | --- | --- |
| 核心与 UI | 默认同源工作台、HTTP、入站 MCP、持久任务/成果与治理 | scripted 是验证默认；真实 AI 需要 Codex 和模型端点，编辑器需 build |
| 自主任务 | Codex 推理、工具选择、上下文压缩、暂停恢复 | 仅选择当前提供的工具；可选择固定版本工作流启动或 MCP 外部 Agent；不自动安装服务、不递归委派 |
| 工作流 | Temporal、React Flow、不可变版本、私有草稿/位置恢复、输入/映射表单、参数绑定、分支/等待/自定义 Adapter | Temporal 可不配置；持久图工作流需要接入；定时触发/独立 Webhook 未实现 |
| MCP / Skill / 节点 | 官方 SDK 注册发现工具、双向 MCP；Skill 固定版本；授权节点配对 | 统一工具目录与按 TTL 自动刷新；Skill 不天然是函数，配对不等于实时在线 |
| 知识 | 内置 SQLite 或 WeKnora；来源绑定、检索前过滤、回查、删除和对账 | 可明确 disabled，工具/MCP/UI 同步关闭；外部故障不静默回退 |
| 身份 | 本地身份、OIDC/ID4、受信 JWKS JWT、独立 HS256、稳定主体映射 | 真实企业 IdP 与长任务委托续期待实际接入；到期不自动扩大原授权 |
| 模型治理 | 可配置网关/模型名，调用及压缩前预算和出域裁定 | 换端点需验证协议兼容；结构化限流暂停，不静默换提供方 |
| 企业扩展 | 项目/企业额度/渠道 Port 与合成项目 Adapter | 真实旧系统、额度分配、IM 未上线 |

公开验证摘要与可复现命令见 [验证说明](validation.md)。原始现场记录与截图留在忽略的本地目录；不以历史测试结果证明当前 HEAD 全部通过。

| 工作块 | 改什么 | 验收例子 |
| --- | --- | --- |

| 自主与接入助手 | 已实现：已发布工作流经受控启动 Adapter 暴露，外部 Agent 复用 MCP；入站助手只生成草稿，管理员确认后登记停用、探针/启用 | 用户只给目标可选已授权能力；其他 Agent 能辅助接入，但修改连接/权限需确认具体草稿 |

CAP-01 验证：444 passed、6 skipped；Ruff、mypy、导入/契约/依赖门禁及编辑器 typecheck/build 通过；独立 wheel 安装通过。Tabbit 验证参数填写/发布、停用自动同步保留草稿、390px 窄屏、旧接口兼容和 SW 缓存升级。这段为 CAP-01 的合成服务/机制与浏览器验证；后续真实模型和容器验收单独记在 VALIDATE-01，不把阶段证据混用。

具体契约和边界见 [能力接入模块](modules/capabilities.md#2-统一工具目录与治理)。不新写执行循环、通用调度引擎或任意代码插件平台；表单组件使用 RJSF 6.11.0/AJV8，兼容 React 19，许可 Apache-2.0；退出保留标准 schema。

## 5. 其他保留缺项

| 缺项 | 下一动作 |
| --- | --- |
| 工作流外部触发 | 实际需要时接 Temporal Schedule / 统一受理 Webhook，不另写定时引擎 |
| 真实企业集成 | 根据 IdP/旧项目/额度/IM 的实际协议配置 Adapter；合成样例不冒充上线 |
| 手机与 HTTPS | 真机可信入口验证上传、审批、预览/下载、断网恢复和撤权；模拟视口不代替 |
| 三次独立自用 | 使用者本人发起、检查、修改和下载并记录，AI 不代写验收 |
| 多副本与 HA | 有明确需求再验证共享状态、租约、迁移和恢复；外接多台服务不等于分布式核心 |
