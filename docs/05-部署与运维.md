## 1. 本机启动与登录

Python 3.13 + uv。以下方式在 U6 隔离环境中实际运行过。正式数据目录沿用已有配置，操作前确认目标环境。

```sh
uv sync --frozen
uv run uvicorn --factory agentos.apps.gateway:create_app --host 127.0.0.1 --port 8800
```

打开 `http://127.0.0.1:8800/ui/`。管理员使用密码登录，首次密码在数据目录 `owner_password.once`，登录后可在偏好设置修改。访问令牌为高级回退，只在可信本机使用，身份文件不发给游客。保持登录使用受控 refresh；游客会话只属于当前标签页，不使用管理员 refresh。

默认 `AGENTOS_DATA_DIR=./data`，模型为 scripted。真实数据目录沿用已配置的非系统盘位置，实际路径只放私有配置。默认示例不证明真实推理或手机可用。

## 2. 真实模型与已有服务复用

配置通过环境或本地 TOML 注入。秘密不写进公开命令、文档和日志；本节只给变量名和占位符。

| 变量 | 用途 |
| --- | --- |
| `AGENTOS_AGENT_RUNTIME` / `AGENTOS_CODEX_BINARY` | 真实模型必须选 codex 与锁定程序；scripted 只用于测试重放 |
| `AGENTOS_RUNTIME_GATEWAY_URL` | 本控制面的受控模型入口，须匹配监听端口 |
| `AGENTOS_MODEL_PROVIDER` | openai_compat 为真实模型；不能与 scripted 引擎配对 |
| `AGENTOS_MODEL_BASE_URL` / `AGENTOS_MODEL_NAME` | 企业网关或 LiteLLM 的兼容端点与已验证模型路由；用户自行选择路由名 |
| `AGENTOS_MODEL_API_KEY` | 私下注入网关单 key；不得进入工作流定义 |
| `AGENTOS_MODEL_EGRESS` | local/cloud，调用前结合数据分类裁定；不自动回退未验证压缩的提供方 |
| `AGENTOS_TEMPORAL_ADDRESS` | 既有 Temporal；开发可用官方持久 start-dev，生产接已有集群 |
| `AGENTOS_RUN_BUDGET_MICROUSD` | 金额预算；0 表示不设金额上限，未配置价格显示“未计价” |
| `AGENTOS_MAX_STEPS` | 通用工具步骤上限；任务 token 护栏见 runtime 配置 |

复用已有模型端点和执行工具，具体设备不构成部署约束。工具、压缩与恢复兼容须在目标端点验证；usage 缺失明确标记估算。新增模型或依赖前核对已有安装，不覆盖原工具和数据。

报告、通用任务和固定协作的真实生成统一委托 Codex；多次内部调用和压缩都经过预算闸门。`local_only` 不调用云端。原 U6 的模型 key 轮换/兜底脚本保留历史用途，不是新主线的默认降级机制；旧配置只有 openai_compat 而未选 Codex 时明确拒绝启动。当前配置、镜像锁定及兼容证据见 [集成部署](09-集成部署.md) 与 [验证说明](validation.md)。

## 3. 页面、节点与知识能力

管理员页面为新任务、任务空间、成果库、能力中心、演示访问、偏好设置。材料在同一输入区粘贴或上传；详情中审批、补资料或提出修改。JSON 只进高级详情；预览和下载使用鉴权请求，不把主令牌放进 URL。

节点在能力中心显示配置、配对与探针结果；配对不表示此刻在线。通过现有受控配对 API 连接授权执行节点后，固定活动协作可研究、真实出图、评审与同任务补充。最多两轮定向返修，已生成视觉复用原 hash；结果未知先对账，生成成功而回传失败只补传。

内置知识后端可摄取、检索、来源回查和删除。任务绑定后端版本，切换只影响新任务。WeKnora v0.8.2 已按官方协议、主体映射和固定 K 真验启用集成配置；异步解析超时对账已有回执，不重复上传。配置与切回规则见 [集成部署](09-集成部署.md#5-外部知识接入)。

## 4. 游客发布与撤销

演示访问页明确选择任务、成果版本、预览、下载与引用片段，发布不可变 revision。游客一键免登，无需邀请码；只读发布范围。定向邀请为可选功能。

暂停对外演示会作废全部免登会话；取消某资源需发布新 revision。浏览器随后读取、刷新、下载或重连都要复核服务端授权。U6 已在隔离环境验证，实际对外开放需用户授权。

## 5. 手机 HTTPS 与恢复

控制面默认回环监听。手机入口需受控私网 HTTPS 代理，证书受手机信任，统一转发 `/ui/` 与 `/v1/`；实际地址与身份材料只存本地配置。不能把电脑回环地址发给手机当入口。真手机仍待验证，按 [开发计划中的手机验收项](04-开发计划.md#5-其他保留缺项) 执行。

真实数据备份使用 SQLite 在线备份或包含完整 WAL 的一致性快照，并同时备份 Asset、身份和必要配置；加密且限制读取权限。先在新的隔离目录恢复，检查任务、审批、hash 与授权，再由用户决定切换，保留原数据。不能用删除卷或重装设备作为默认修复。

SW 只缓存 `/ui/` 静态外壳，不缓存 API 或私有素材；升级后刷新并核对详情直开。当前 SW 为 v38；源代码和实际目标环境升级应分别验证，不依赖本地历史截图。备份/恢复与生产部署需要在目标环境验收。


## 7. 私有工作流草稿与接入助手

工作流草稿自动保存至当前账号服务端存储，回到列表或刷新后用“恢复草稿”继续；画布位置和输入一并恢复。未确认保存时先重试或导出；多标签冲突不能强行覆盖。草稿不替代发布版本，执行只使用已发布定义。

能力中心的“连接 MCP”先生成配置草稿；其他 Agent 可通过入站 mcp_connection_propose 辅助生成。同租户管理员在 MCP 服务页审阅具体端点、命令参数、环境引用和声明风险；确认只登记停用连接，不执行命令。探针成功后再启用，工具目录及工作流自动发现；选择“外部 Agent”时复用 MCP 工具协议。凭据配置在部署端环境，草稿只存 env:VARIABLE 引用。

自主工作流调用返回子任务句柄，不等待成果；用 workflow.status 查看真实状态。最多一层委派，预算从父任务预留，结束结算；父任务与子任务分别显示在任务列表。真实外部 Agent 可达性、模型费用与组织额度仍按现场配置核验，不因注册成功推断业务成功。
