## 1. 当前任务

完成已确认的四项完善：私有工作流草稿持久化、输入/映射表单、固定工作流与 MCP 外部 Agent 能力化、受控 MCP 接入草稿。双边文档/版本锁及隐私复核后本地提交，不推送。

## 2. 变更

草稿复用 SQLite，按 tenant/subject 隔离、revision 条件写、删除墓碑防旧标签复写；保存未完成高级配置、位置、输入与启动幂等键。前端串行合并保存，丢失回执先回读，冲突不换 revision。切页保存失败留在编辑页，刷新提示未保存；会话切换拒绝旧队列请求。导出包含私有编辑快照，未完成 JSON 可恢复。

RJSF/AJV 复用到流程运行输入，普通输入字段与直接上游映射有选择控件；映射与普通参数分开合并，复杂 schema/嵌套映射进高级详情。发布校验引用与依赖，启动缺输入不入队。

固定工作流经薄 ToolPort 启动能力进入同一目录，返回 launch_only 句柄；既有 Temporal/治理执行节点。委派与父预算预留同事务，分配不超过剩余预算一半、终态结算/保守计入未决费用，最多一层。外部 Agent 复用官方 MCP Hub，以 agent 连接类型标识；不另写协议或执行循环。

MCP 新增目录、固定工作流列表/启动与连接提案；提案按主体/配置稳定标识可重放，凭据只存环境引用。管理员审阅具体配置/hash 后原子登记为停用连接，不能覆盖既有连接；探针成功再启用，失败仍停用。默认 UI 连接也先走草稿。新增 ADR-0024，模块图/阅读版与双边文档对应更新，SW v42。
