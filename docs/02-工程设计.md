## 3. 状态与并发

### 3.1 任务状态

| 状态 | 含义 |
| --- | --- |
| `created` | 请求已受理 |
| `planning` | 正在形成执行计划 |
| `awaiting_input` | 等待用户补充 |
| `awaiting_resources` | 等待执行资源 |
| `running` | 正在执行 |
| `awaiting_approval` | 等待已绑定调用的审批 |
| `awaiting_review` | 等待评审 |
| `paused` | 暂停，按实际恢复条件继续 |
| `cancel_requested` | 已请求取消，尚未确认停止 |
| `succeeded` / `failed` / `cancelled` | 已完成 / 失败 / 已取消的终态 |

合法迁移由 `kernel/states.py` 裁定，前端不能自行设置状态。步骤还区分 `prepared`、`dispatched`、`pending_external` 和 `uncertain`；结果未知是对账状态，不得当成可直接重放的失败。

### 3.2 租约与原子恢复

Worker 领取任务后维持心跳。`lease_fence` 独立于业务版本号，提交效果时核对 fence、所有者和有效期。失去租约取消当前驱动，其他任务仍可继续。

`StoreProtocol.resume_with_checkpoint` 用预期状态与版本做条件更新，在同一事务内保存检查点、恢复状态、返修事件和后续 Job。并发或重复补充不得生成重复恢复动作。网络 I/O 不在持久化事务内执行。

Codex 限流暂停使用 `StoreProtocol.resume_runtime` 原子检查状态、清除错误并唤醒原任务。恢复入口要求本人资源权限与 write scope；未决效果、待审批、重复请求和终态均拒绝。已确认副作用复用原 step/attempt，不重新执行。

## 4. 输入、上下文与成果

| 对象 | 实现约束 |
| --- | --- |
| 文本材料 | UTF-8 `.txt` / `.md`；最多 3 份，单份 64 KiB，合计 128 KiB；服务端校验 |
| 材料 ID | 稳定上传幂等，绑定主体和任务；客户端字段不能证明归属 |
| 上下文 | 服务端读取授权前序任务、材料与成果，过滤伪造的上下文或后端绑定 |
| 报告 | 必备章节、授权引用、字数、日期与人民币金额检查先于保存审批 |
| 修改 | 关联新任务和新成果版本，保存父成果关系，旧版字节不变 |
| 来源 | 固定材料 / 知识源、后端、版本及行范围，允许授权回查 |
| 下载 | 受鉴权请求，核对动作权限；响应不暴露内部文件路径 |

字数、日期、金额与引用检查是确定性规则，不能扩展解释为完整语义真实性保证。没有依据的字段须保留为待确认。Markdown 预览禁用原始 HTML，限制链接协议，动态内容安全渲染。

## 5. 执行策略

### 5.1 简单报告

固定 `material-report` Skill 和版本，依次读取授权材料、调用模型生成、检查、经审批保存、登记不可变成果。模型上下文与累计 token 受护栏约束；长度修正调用有上限。检查失败不得登记合格报告。

### 5.2 有界活动协作

计划 v1 为研究和设计、汇总、评审、交付的合法 DAG。来源不足时等待补充；同一任务形成计划 v2，仅重做受影响的研究与汇总，复用视觉成果。最多两轮补充，超限停止。

视觉步骤固定真实节点、工具和版本，参数先保存再审批，派发使用稳定步骤键。生成完成后校验回传 SHA-256。回传失败时保留已生成状态，只允许补传相同成果。

### 5.3 通用计划

仅执行受限计划，角色只可读取直接依赖的输出，空工具白名单拒绝调用。审批前持久化待执行参数与上下文，恢复使用原调用。模型调用轮次、工具步骤和 token 均有边界。

### 5.4 集成工作流与新真实运行时

工作流公开节点为 AI、工具、条件、等待、自定义；业务模板节点由正规任务入口生成。图发布后版本不可变；输入按 schema 校验，引用只能读取已声明依赖的输出，custom 只能调用服务端注册实现。Temporal 拥有 DAG/计时/信号/重试；AgentOS 的稳定步骤键、审批指纹和未知结果对账决定副作用。首版单 worker 的工具提交串行，逻辑分支与等待可并行，不承诺同一 run 并行写检查点。

Codex 每个 agent 节点绑定一个 thread，turn 内可有多次模型和工具调用。恢复先执行原已批准参数，再交回引擎。原始 model body 不进入公共事件，usage 缺失保守估算；压缩与普通请求共用 run/身份/预算/数据出域闸门。提供方协议差异由现有网关处理，不新写模型转换协议。压缩或推理遇到结构化 429 时保留阶段并暂停，由明确操作恢复原任务；成功效果回执持久化，恢复仅补有界确认元数据，不重放材料和 Skill 正文。

下图为工作流 Agent 节点产生副作用时的治理关系；每次推理及压缩都经过相同 ModelGate。单 Agent 任务可直接进入驱动，不要求额外工作流。

组件调用与单次动作时序见 [执行模块](modules/execution.md)，总体分层见 [总体架构](01-总体架构.md)。

企业 JWT 或浏览器身份到期后停止执行，原授权不会因刷新而延长；支持配置内省与持久撤权。现阶段浏览器会话需重新登录，暂不代管 offline refresh token。企业长任务服务身份和委托续期需按实际 IdP 另验。

### 5.5 能力发现与自主任务

MCP 注册时发现工具并缓存 schema，目录读取按 TTL 刷新，失败保留不可用诊断。统一 ToolPort 目录向 HTTP、工作流和 Codex 提供 schema/风险/scope/契约摘要；工作流编辑器 15 秒及聚焦同步，参数表单复用 RJSF/AJV。HTTP 发布由服务端固定工具契约，漂移拒绝派发，已成功效果不重放。知识支持 disabled，模型、MCP 与 UI 同步关闭。普通 Codex 任务可自主选择已有工具，不要求先定义图；外部 Agent/已有流程自主选择和接入管理 MCP 后置，见 [能力接入模块](modules/capabilities.md)。

## 6. 模型、技能与知识

真实推理由 Codex 经调用前治理闸门进入企业网关或 LiteLLM；Responses→Chat 等协议转换复用网关实现。模型端点由部署方配置，云端仅在显式选择与出域策略允许时使用；当前主线遇到限流暂停，不自动换 key 或模型。旧 ModelRouter 的轮换/降级仍保留兼容与确定性测试，不作为当前 Codex 主线承诺。已有输出不能混入第二模型；SSE 缺少结束标记或工具参数损坏视为错误。

Skill 安装登记元数据，任务按需读取实际正文和资源，固定版本与摘要。禁用影响后续调用，不覆盖运行中的不可变版本。

知识检索固定所选后端版本，切换只影响新任务。WeKnora 持久来源→租户/主体/ACL/文档/KB/内容版本映射；请求前发送允许的 knowledge_ids，响应再核对文档与 KB。回查同时验证父文档和引用；删除先撤销本地授权，再对账远端异步删除。没有回执的摄取保持 uncertain，禁止盲目重传。上游 SQLite 缺失 FTS5 的镜像不能作为可用检索后端，本次集成使用其官方支持的 Qdrant。

## 7. 访问授权与演示发布

| 请求 | 管理员 | 游客 |
| --- | --- | --- |
| 任务、成果与来源读取 | 所属租户的业务授权范围 | 发布清单中的确切资源与版本 |
| 预览 / 下载 | 分别核权 | 动作必须显式开放 |
| 创建、修改、取消、审批、管理能力 | 按策略和预算执行 | 拒绝 |
| 全库检索、长期记忆与原始审计 | 按对应授权 | 拒绝 |
| 会话刷新和退出 | 本人会话 | 仅本人游客会话 |

游客会话只存当前标签页；撤权后不能使用管理员 refresh 凭据。发布 revision 不可变，新成果默认不自动公开。源权限收紧或来源失效时撤下关联发布资源，不改写原始不可变文件。

每次读取和每批流事件发送前复核授权。失效会话返回 401；有效身份禁止功能返回 403；游客不可读或不存在的资源统一返回 404。恢复备份须防止已撤销会话复活。

## 9. 前端与恢复

前端通过同源 `/ui/` 提供，使用哈希路由和共用 API、鉴权、错误、主题与预览模块。事件流从持久游标续接，快照和增量去重。刷新与重连查询原任务，不重新提交目标。

草稿、材料 ID、展开详情与阅读位置应保留；退出或 401 清除敏感视图、请求和 Blob。Service Worker 仅缓存静态外壳，不缓存 API 或私有素材。升级须检查旧缓存、详情直开与静态资源一致性。

## 10. 验证与交付

### 10.1 固定样本

| 样本 | 内容 | 判据 |
| --- | --- | --- |
| A | 主体、租户、任务和成果权限 | 越权拒绝，无正文泄露和副作用 |
| S | 日期地点预算、冲突、信息缺失 | 真实材料消费、引用、弃答、修改版本与 hash |
| K | 重复文档、权限哨兵、删除来源 | 摄取、检索、引用、隔离、删除与切回 |
| C | 活动方案与视觉，缺来源后补充 | 同任务计划升级、定向返修、视觉只生成一次 |
| F | 审批、未知结果、断流、预算、缓存 | 原任务恢复、稳定幂等与失败状态 |

冻结 JSON 位于 [固定样本目录](../tests/fixtures/u4/README.md)。保持样本、需求 ID 和预期，不能随实现结果放宽断言。

### 10.2 负向矩阵

所有拒绝同时检查“无数据正文泄露、无新 job/副作用、资源归属未变、必要审计存在”，不能只断言状态码。测试直接 HTTP/服务调用，绕过 UI。

| 编号 | 攻击/故障输入 | 独立预期 |
| --- | --- | --- |
| R01 | guest-A 换T2/T3、guest-B manifest、另一tenant标识；列表计数/分页猜资源 | 不返回任务/标题/计数/正文/资源元数据 |
| R02 | T1 路由带 F3、共享asset挂到别run、parent/child/旧版跳转 | 按实际关系及 manifest 校验，不扩大范围 |
| R03 | 可预览F1-v1但下载关闭；请求v2/缩略图/媒体range/附件/引用全文 | 每种读入口独立核权，range不能绕过，未发布资源拒绝 |
| R04 | 通过 trace/events/stream/错误/导出读 owner 参数、系统指令、path、endpoint、秘密或S2哨兵 | 白名单投影无这些字段和内容；日志不带兑换码/令牌 |
| R05 | guest直接提交任务/voice/webhook、workflow start/publish、approval、cancel/reconcile、upload/push/fetch/Hub管理 | 拒绝且无执行；登录/刷新/退出只能作用本人会话 |
| R06 | 伪造role/header主体；guest refresh；他人refresh；重用兑换码 | 不提升权限、不签owner、不跨主体，兑换只成功一次；过期不延长 |
| R07 | 撤销后旧token/refresh/签名/直开/download/已开流/重连/旧SW缓存 | 后续读取立即拒绝；流发送前复核并关闭；页面清理；私有缓存不返回数据 |
| R08 | 恢复撤销前备份、数据库迁移旧无主资源 | 不复活guestgrant；未知归属不默认分享；admin原业务恢复 |
| R09 | Agent/Skill/MCP返回诱导越权读取/写入；子角色要求全库/记忆/另run资源 | 按受限委托权限拒绝并记录，模型没有授权效力 |
| R10 | 两知识Adapter检索/resolve混用backend/source/chunk/version、删除后resolve、缓存命中私有哨兵 | 引用归属固定、双过滤、删除失效；不能把owner平台凭据当权限 |
| R11 | 计划有环/缺依赖/预算矛盾、审批参数变更、已批准调用重启 | 派发拒绝或重新裁定；原调用参数固定；无二次已确认效果 |
| R12 | 回执丢失、结果未知、节点断连、生成成功回传失败、无限评审 | stable key与对账；只补传；预算内停止；终态/未决项真实 |
| R13 | token增量乱序/重复、快照与事件竞态、断网后刷新/重启 | 消息/事件不丢不重复，不重新提交目标；原run可续接 |
