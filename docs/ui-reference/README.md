## 在任何有本仓库的机器打开

可直接用浏览器打开 index.html。若自动化工具需要HTTP，从仓库根运行：

```sh
python3 -m http.server 59573 --bind 127.0.0.1 --directory docs/ui-reference
```

打开 http://127.0.0.1:59573/ 。端口占用时换空闲端口；这是本机静态预览，不是线上服务。另一台机器上的AI需要相同仓库/文件，再在自己的机器启动；不要把本机localhost当跨机器分享链接。不启动第二个AgentOS网关，不接生产数据库。

独立导出内含宿主兼容层与样板内容，不需要visualize插件运行；包装器的Lucide图标资源通过CDN加载，断网时文字与布局仍可读，不能宣称完全离线资源。所有设计交互不调用AgentOS API。导出采用sandbox iframe；浏览器自动化定位使用 `page.frameLocator("iframe")`，进入frame后读按钮/内容。

## 必须浏览的交互路径

1. 新任务→“整理一份项目周报”→对话/执行图/成果→来源片段与版本；看输入/文字/工具事件/成果并排。
2. “完成活动方案与素材”→执行图→研究/设计/评审详情→返修轨迹→成果；实线为当前DAG，虚线为历史，不保存环形计划。
3. “生成一张宣传视觉”→确认卡→允许/拒绝；确认嵌在任务内，不是左侧一级菜单。
4. 能力中心→MCP/Skills/知识/设备→内置/WeKnora样例选择→新任务；旧示例绑定保持；不是实际外部服务探针。
5. 示例回放/暂停、成果修改产生新版本、回传失败只补传；不把演示动画当真实流式。
6. 手机尺寸：导航抽屉、对话、执行图、成果/步骤详情，长中文内容不整体横向溢出。

## 参照与实现边界

U3接受的是总体风格与使用结构：中性表面、石墨主要操作、蓝紫强调、对话优先、电脑旁栏/手机按需详情；不是所有样板文案和合成数据必须照抄。实现拆入现有frontend组件与模块，生产由 `/ui/` 同源提供；不能把本目录当独立真实产品发布，也不能通过模拟状态绕开后端。

本目录保留原样板源码和可运行导出，避免其他AI必须访问本会话才能知道目标。若以后更新视觉基准，修改规范源码、同步导出并重新实际浏览器核对；不要只修改截图。导出来自visualize的render.py，无需执行者安装它即可阅读/运行已导出文件；需要重新导出时用可用的同名工具或等价独立包装，记录变更。
