# AgentOS

AgentOS 是可自托管的 AI 集成与治理底座，把已有模型、Agent、知识、工具、技能、身份和业务系统连接起来，统一任务、权限、审批、成果与成本。默认提供 Web 工作台，也通过 HTTP 与 MCP 服务其他应用和 Agent。

从一个核心开始，按需连接能力。同机、远程机器、企业已有系统与云端可以组合部署，不要求特定设备或操作系统。真实推理复用 Codex，持久工作流按需接入 Temporal；模型、知识和企业身份无需为了使用平台全部重建。

## 当前能力与边界

- 同源任务工作台、真实正文流、持久事件与恢复。
- 资料报告、来源回查、补充修改与不可变成果版本。
- Codex 自主选择已有工具，调用前核权、审批、预算与出域裁定。
- 官方 MCP 双向互通、固定版本 Skill、授权执行节点。
- React Flow 版本化工作流、Temporal 持久编排与自定义 Adapter。
- 可选 OIDC/ID4/JWT 身份和 WeKnora 知识接入。

核心已能独立启动；完整的功能关闭、统一能力目录、接入后实时节点同步、schema 参数表单及 Agent 接入助手仍需补齐。当前实现与目标分别记录，详见 [能力接入模块](docs/modules/capabilities.md) 与 [开发计划](docs/04-开发计划.md)。

## 启动核心

Python 3.13 + uv：

```sh
uv sync --frozen
uv run uvicorn --factory agentos.apps.gateway:create_app --host 127.0.0.1 --port 8800
```

打开 `http://127.0.0.1:8800/ui/`。首次管理员密码保存在数据目录 `owner_password.once`。无配置默认为 scripted 验证环境；真实 AI 使用 [最小配置示例](deploy/core.example.toml) 配置 Codex 和自己的模型端点。可视编辑器构建与能力连接见 [集成部署](docs/09-集成部署.md)。
